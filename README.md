# Second Chance Thrift

A Windows first-person thrift-store simulator. Grandpa has retired and handed you his little store. Find secondhand goods, clean and restore them, stock your displays and grow the business.

**[Download v0.6.0 for Windows (ZIP, 359 MB)](https://github.com/Shad0w746/second-chance-thrift-downloads/releases/download/v0.6.0/SecondChanceThrift-v0.6.0-Windows-GameOnly.zip)**

1. Download the ZIP above and choose **Extract All**.
2. Open **SecondChanceThrift.exe** inside the extracted folder.
3. Keep the accompanying `Engine` and `ThriftStore` folders beside it.

Windows 10/11 64-bit with DirectX 11 graphics is the target. Unreal Engine, Blender, Python and OBS do not need to be installed. If Windows reports missing runtime components, run the included `Engine/Extras/Redist/en-us/UEPrereqSetup_x64.exe` and try again. Hardware performance and clean-machine compatibility are still being evaluated.

This early playtest includes twenty thrift goods, a five-slot carry bar, cleaning/repair/restoration benches, a windowed starter shop and **Bargain Bean**, a silly customer who visits and buys affordable displayed goods.

Use **W/A/S/D** and the mouse to move, **E** to interact, **Tab** for inventory, **1-5** to select carried goods, and **Esc** to pause. Full instructions and a first-sale scenario are in `START-HERE.txt`. To see Bean make a purchase, list a good at or below its estimated value and close the menu; allow about a minute for the visit.

This is the **game-only** download. Recording stays Off; the optional recording/feedback companion is not included. Use `FEEDBACK.txt` for notes and send it to the person who shared the game. Nothing uploads your feedback automatically.
